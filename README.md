# Africa Store

Online catalog for an African fashion store in Morocco. The site is in French.

## Features
- Home page with featured categories
- Category pages: T-shirts, sets (Ensembles) and accessories
- Product cards with image, name and price (in MAD)
- "Acheter" button that opens WhatsApp with a pre-filled message containing the product reference and price
- Responsive design (mobile and desktop)

## Technologies
HTML, CSS, JavaScript
